# 🎨 pArt — Pixel Art Maker

pArt is a Python application that allows users to create pixel art using a grid.

## ✨ Features

- 🎨 **Color Picker:** Choose your own colors.
- 🖌️ **Drawing:** Click or drag to color individual squares.
- 🧹 **Eraser:** Erase parts of your artwork.
- 📐 **Multiple Grid Sizes:** Choose between 16×16, 32×32, and 64×64 grids.
- 🖥️ **Simple Interface:** Create pixel art using a straightforward graphical interface.

## 🛠️ Built With

- Python
- Tkinter

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Run the application:

   ```bash
   python pArt.py
   ```

## 🎯 Purpose

The goal of pArt is to make creating pixel art simple and accessible, allowing users to experiment with colors and create their own artwork one square at a time.

## 📌 Future Improvements
